# D&D 3.5 Platform

### Questo progetto punta a creare una piattaforma dove poter giocare insieme ad altre persone alla versione 3.5 di D&D, ci saranno mappe personalizzabili, chat di gruppo e singole, possibilità di creare le proprie campagne e generatori di npc casuali e tanto altro.

## 🛠 Tecnologie
- Java 21
- Spring Boot 3
- Spring Web (REST API)
- Spring Data JPA
- Hibernate (JPA provider)
- Maven
- MySQL / PostgreSQL
- Docker

## 🧱 Architettura

- Architettura a microservizi
- Separazione per layer:
  - Controller
  - Service
  - Repository
  - Entity / DTO
- Comunicazione REST
- Naming e struttura orientate alla manutenibilità

## 🤖 Sviluppo e percorso formativo assistiti da AI

Il progetto viene sviluppato con il supporto sia di **Claude Code** sia di **OpenAI Codex**.
Gli agenti operano come collaboratori tecnici, senior mentor e reviewer: aiutano nell'analisi dei
requisiti, nel confronto delle alternative, nel debugging e nella revisione del codice.

Lo sviluppatore mantiene la responsabilità delle decisioni e dell'apprendimento. Nei task
formativi scrive normalmente l'implementazione e deve saper spiegare flusso, responsabilità,
rischi e verifiche. Gli agenti possono implementare modifiche soltanto in seguito a una delega
esplicita e circoscritta.

Il lavoro procede attraverso micro-passi verificabili. Un task non viene considerato concluso
finché i suoi criteri di accettazione non sono stati realmente controllati.
